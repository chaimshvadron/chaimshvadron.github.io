Privacy Policy, OpenClaw Agent

Last updated: November 8, 2026

OpenClaw Agent is a private application used only by its owner, Chaim Shvadron. It is not available to any other person.

Data accessed

  • Gmail: read only access (gmail.readonly) to the owner's own mailbox, to search and summarize messages at the owner's request.
  • Google Calendar: access to the owner's own calendar, to read events and create events the owner asks for.

How data is used and stored

Data is used only to answer the owner's own requests. OAuth tokens are stored encrypted on the owner's private server. Message content needed to answer a request is processed by the AI model provider (Anthropic) and is not sold, shared or used for advertising.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
